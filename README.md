# 悬浮球 - 投递助手（v0.2.0）

Chrome / Edge 通用扩展，双入口：

1. **网页悬浮球**：所有网页右下角出现可拖拽 💼 悬浮球，点击展开面板
2. **工具栏弹窗**：点击浏览器工具栏的扩展图标，弹出面板

两个入口均含「添加投递信息」「详情」按钮。**当前版本按钮仅 UI，功能待后续迭代。**

## 安装（Chrome 与 Edge 步骤相同）

1. 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展」，选择本目录（`float-ball-extension`）
4. 卡片显示「未打包的扩展程序」标签 = **正常**，开发模式扩展都这样
5. 打开任意普通网页（如 https://www.bing.com ）并按 `F5` 刷新，右下角出现 💼 悬浮球即成功
6. （建议）点击工具栏拼图图标 → 把「悬浮球 - 投递助手」钉住，之后可直接点图标弹出面板

## 使用

- **悬浮球**：按住拖拽（松手吸附边缘、按站点记忆位置）；单击展开/收起面板；点页面空白处收起
- **工具栏图标**：单击弹出面板
- **按钮**：点击仅输出控制台占位 log（F12 可见）

## 已知边界

- `chrome://`、`edge://`、新标签页、扩展商店等浏览器内部页面：悬浮球不注入，且 Chrome 会**强制置灰所有扩展图标**（浏览器安全限制，任何扩展都一样）——请在普通网页上测试
- iframe 内不显示悬浮球，每个标签页仅一个球
- 修改代码后需回 `chrome://extensions` 点击卡片上的 🔄「重新加载」按钮，再刷新网页

## 目录结构

| 文件 | 职责 |
|---|---|
| manifest.json | MV3 清单：content script + 工具栏 action |
| content.css | 悬浮球宿主元素定位样式 |
| content.js | 悬浮球全部逻辑（Shadow DOM 隔离） |
| popup.html / popup.js | 工具栏弹窗面板（同款两按钮） |
